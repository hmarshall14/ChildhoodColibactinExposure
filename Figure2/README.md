Contains the R markdowns for the data presented in the section 'Prevalence and mutation burden of colibactin mutagenesis.'

prevalence_and_burden_colibactin.Rmd contains code used to generate summary statistics of colibactin mutation prevalence, and to compare colibactin associated mutation burden between left and right colon, children and adult populations. It contains code to construct Figure 2.B and 2.C

compare_mutational_age.Rmd contains code to estimate mutational ages of each crypt and biopsy and to generate Figure 2.A

compare_coding_mutations.Rmd contains code to compare number of coding mutations between crypts based on presence of colibactin mutagenesis.
