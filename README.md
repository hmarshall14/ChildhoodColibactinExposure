# ChildhoodColibactinExposure

This repository contains the data and code used to generate analyses and figures in the manuscript: Marshall et al. 'Common early-life exposure of the colorectal epithelium to the microbiome-derived mutagen colibactin'.

Folder Data contains the main data spreadsheets used in this analysis. Signatures contains the outputs from SigProfiler and msigHDP for signature extraction. Phylogenetic_Trees contains the phylogenetic trees constructed in this analysis. 

Within each folder entitled 'FigureX', the relevant R markdowns are deposited for the associated analyses within that section.
