This folder contains the Rmarkdown documents for the construction of the Supplementary Figures 2-6.

supplementary_figure_2_pole_mutyh_comparisons.Rmd contains script for plotting Supplementary Figure 2 comparing observed mutation burdens to estimated rates of mutagenesis in individuals with inherited MUTYH and DNA Polymerase mutations

supplementary_figure_3_5_coding_and_early_branches.nb.Rmd contains script for plotting Supplementary Figure 3 and 5 which illustrate attribution of mutational signatures to 1) coding mutations and 2) early phylogenetic branches

supplementary_figure_4_colibactin_burden_and_age.Rmd contains script for plotting aggregate SBS88 and ID18 mutation burdens per crypt versus age

supplementary_figure_6_metagenomic_analysis.nb.Rmd contains script for plotting assignment of unmapped reads to either E. Coli or pks+ gene cluster island using KrakenUniq, Metaphlan, bowtie2 and Lexicmap.
