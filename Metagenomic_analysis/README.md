Contains code for the metagenomic analyses incorporated in this manuscript.

`kraken_metaphlan_consensus_species.tsv` is the output from the microbiome consensus calling of read abundances per sample

`supplementary_figure_metagenomics_analysis.Rmd` contains the script for generating Supplementary Figure 10.

`taxon_annotation.R` is used to annotate each species as either contaminant, oral/gut flora, or unclassified.
