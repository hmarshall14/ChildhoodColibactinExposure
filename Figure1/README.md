Contains code used for summary analyses for sections: Study participants and samples, Mutational signatures, Background mutation rates. 

study_participants_and_samples.Rmd contains code for study characterisation and Figure 1.B
background_mutations_rates.Rmd contains code for estimating rate of background SBS and ID mutations in histologically normal individuals, comparisons between histologically normal and IBD individuals, and summary of structural variants.
anbackground_mutations_rates.Rmd also describes the the construction of Figure 1.C and 1.D
